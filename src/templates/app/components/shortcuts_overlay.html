{% comment %} Keyboard shortcut cheat sheet. Triggered by `?` (Shift+/) — searchShortcut.js dispatches the `shortcuts-toggle` window event when it sees the key. {% endcomment %}

Keyboard shortcuts

Open command palette K
Focus search /
Toggle this overlay ?
Move down a row J
Move up a row K
Go home GthenH
Go to calendar GthenD
Go to lists GthenL
Close overlays Esc
J / K only navigate items marked for row navigation. Most media-list and dashboard cards opt in.
