ListenBrainz / Multi-Scrobbler

Forward listens from multi-scrobbler (or any client speaking the ListenBrainz submit-listens protocol) into Yamtrack. Each listen becomes a Play row, matched to a tracked record by (artist, title); unmatched listens are still saved and shown on the Music page.

Multi-Scrobbler client config

  1. In multi-scrobbler, add a listenbrainz client. Set the URL to: {# djlint:off #}
    {% include "app/icons/copy.svg" with classes="w-5 h-5 text-fg-muted group-hover:text-indigo-400 transition-colors" %}
    {# djlint:on #}

  2. For the token, paste your API token from the top of this page.
  3. Verify by hitting the validate-token endpoint: {# djlint:off #}
    {% include "app/icons/copy.svg" with classes="w-5 h-5 text-fg-muted group-hover:text-indigo-400 transition-colors" %}
    {# djlint:on #}

    Send Authorization: Token <your-api-token>; expect a JSON response with "valid": true.
